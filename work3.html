Network Health Monitor — PowerShell + Teams Alerts

I developed an event-driven network monitoring system that checks multiple devices and sends real-time alerts to Microsoft Teams only when a device is down or encounters an error. Using PowerShell and Power Automate, the solution delivers clean, readable alerts, reduces noise from constant reporting, and ensures IT teams can respond immediately to network issues.

The Challenge

Traditional network monitoring tools often flood IT teams with repetitive or unnecessary notifications, making it difficult to identify truly critical issues. Our environment required a more efficient system — one that could monitor multiple devices continuously, detect real failures in real time, and communicate only meaningful alerts without overwhelming users with duplicate reports.

The Solution

I developed an event-driven system using PowerShell and Microsoft Power Automate that intelligently checks device health. Alerts are automatically formatted and delivered to Microsoft Teams for immediate visibility. This approach significantly reduced alert noise and improved response times for IT staff.
