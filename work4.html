Platform Architecture & Governance

SHAHHUB is an active cyber operations and IT command center designed around a zero-trust, privacy-first model. Built to bridge technical cybersecurity workflows with actionable system administration tools, every module guarantees strict data isolation, persistent row-level security (RLS), and zero telemetry.

Privacy-First Auth

Google & Microsoft OAuth integration with rate-limited guest access. No password storage required.

Row-Level Security

All stored entities enforce strict owner-or-admin RLS policies across database records.

Zero Telemetry

Session diagnostics, WHOIS lookups, and connection checks are never saved or monitored.

Active Modules & Feature Suite

Active Feature

1. Dashboard — Cyber Situation Awareness

Read-only global threat intelligence providing high-level operational visibility. Features live Check Point global threat-map embeds, active threat telemetry metrics, attack distribution analytics, and a real-time incident event feed—operating without gathering user or session data.

Session-Only

2. My Connection

User-triggered public IP detection equipped with real-time geo-intelligence (city, country, ISP, ASN, geographic coordinates). Completely session-only with zero data retention and a single-click memory purge.

Zero-Logging

3. DNS & Intelligence

Deep DNS record inspection, domain WHOIS records, and reverse-DNS lookups routed through public APIs and rendered in a terminal interface. Queries are never stored or logged on platform servers.

Active Feature

4. Traffic & Network Health

Comprehensive network analysis suite for diagnosing packet streams and routing topology.

  • AI PCAP Analysis (.pcap/.pcapng)
  • Anomalies & Protocol Distribution
  • CIDR Subnet Calculator
  • MTR Diagnostics Table
Active Feature

5. Security & Testing

Security auditing, breach lookup, and automated assessment utilities built with owner+admin RLS protection.

  • Vulnerability Vault (Nikto/Nessus/Burp/Metasploit)
  • Password Entropy & Crack-Time Simulator
  • AI-Assisted HIBP Breach Lookup
  • Phishing Analysis Lab
  • AI SOC Guidance Assistant
Active Feature

6. Remote Command Center

Centralized operational hub with curated links to AnyDesk, TeamViewer, Microsoft 365, Entra ID, Intune, Azure, AWS, and GCP admin portals. Includes copyable RDP, SSH, and PowerShell reference commands with zero credential storage.

Active Feature

7. DevOps Lab

Curated script repository containing Bash, PowerShell, Python, Terraform, and YAML automation files. Supports syntax-highlighted code viewing, instant clipboard copying, quick-start templates, and categorization backed by strict RLS rules.

Active Feature

8. IT Fix-It Center

An operational troubleshooting desk for system administrators. Contains categorised CLI commands for Windows repair, Microsoft Outlook fixes, HP hardware utilities, and system diagnostics alongside official vendor support portals.

Active Feature

9. Documentation & Wiki

An AI-assisted knowledge base covering networking, cybersecurity, hardware repair, script execution, and DevOps workflows. Features difficulty indicators, instant search, and the integrated Resume-Ready Project Guide.

1-Hour Expiry

Generates disposable @shahhub.local email addresses featuring a 1-hour lifecycle and a simulated inbox to safely test web registration flows and conduct email headers/phishing analysis without risking main accounts.
