Aether — Admin & Compliance AI Agents

Human-in-the-loop AI agents that automate collections, follow-ups, bookings, grants and compliance for Singapore SMEs.

2nd Place Winner at the 14th CEO Lounge 2026 TR3 Hackathon (James Cook University Singapore).

Overview

Small and medium-sized enterprises (SMEs) in Singapore that sell on credit often lack dedicated finance teams, leaving owners to spend hundreds of hours manually chasing overdue invoices and managing administrative burdens. Aether solves this by deploying specialized AI agents (Collections, Follow-ups, Bookings, Grants, and Compliance) that automate administrative tasks while ensuring strict human oversight.

Key Features & Architecture

  • Human-in-the-Loop (HITL) Governance: A robust 3-stage gatekeeper framework ensuring AI drafts are reviewed, edited, and explicitly approved by the owner before any external dispatch.
  • Multi-Agent Workflow: Handles automated invoice tracking, customer follow-up reminders, booking management, grant matching, and regulatory compliance checklists.
  • Enterprise Security & Privacy: Features password-encrypted monthly PDF reporting (AES), PII upload warning gates, and strict data governance (zero 3rd-party data monetization).

Technology Stack

  • Frontend: Next.js 15 (App Router), React 19, Tailwind CSS (Hosted on Vercel).
  • Backend & API: Express.js REST API with Zod validation, Groq API integration (Hosted on Render).
  • Database & ORM: Supabase PostgreSQL database managed via Prisma ORM.
